### PROYECTO: ANÁLISIS COMERCIAL E INVENTARIOS — H-E-B

**Dashboards desarrollados para el análisis de ventas, inventario y órdenes de compra en 93 tiendas y 10 categorías.**

**01. Histórico de Ventas e Inventario Promedio Mensual**
Dashboard enfocado en analizar la relación entre el comportamiento de las ventas y el inventario promedio mensual, permitiendo identificar periodos con **bajas ventas asociadas a niveles elevados de inventario**, así como posibles oportunidades de optimización.

**02. Participación de Producto por Categoría**
Dashboard diseñado para analizar la participación y disponibilidad de productos dentro de cada categoría, identificando **tiendas sin inventario de productos específicos** de acuerdo con el catálogo correspondiente a cada categoría y detectando oportunidades de abastecimiento.

**03. Desglose de Órdenes de Compra**
Dashboard para analizar las órdenes de compra realizadas por tienda y producto, comparando los pedidos con las **ventas promedio** para identificar posibles escenarios de **bajo inventario, sobreinventario y oportunidades de reposición**, facilitando la toma de decisiones comerciales.
